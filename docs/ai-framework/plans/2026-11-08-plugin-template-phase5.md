# 阶段计划：PLT-5 全能参考插件（并集基底＋减法）

> 设计哲学变更（2026-11-08 用户定）：PLT-1~4 的「极简基底＋按需接线」反转为「**全量并集基底＋减法**」——
> 模板插件 = 11 家已迁移插件 ∪ console-mockup ∪ PLUGIN-CAPABILITIES.md 的**功能并集**，全部接真数据可跑；
> 新供应商插件 = 从全家桶里**做减法**（删视图/删段/删代码）。
> 依据：phase4 终验 + onetim 演练配方（plugin-template/docs/onetim-walkthrough.md）+ 11 家迁移实码。

| 项 | 值 |

## 1. 红线（沿用 PLT-4 全部＋新增）

1. 并集基准 = **13 视图 mockup ∪ 11 家已迁移实码 ∪ PLUGIN-CAPABILITIES.md**；不发明三者之外的功能
2. 免费源预配仅限零凭据源（temp.tf/g22do/guerrilla/freecustom）；收费源出厂空串

## 3. 批次

### 批 A：通用能力端点层（骨架→全家桶的地基）

| Task | 内容 |
|------|------|
| T-A1 | pluginsdk 新增 `pool` 包：通用账号模型（id/label/status/quota.View/egress 绑定/最近使用）＋线程安全 Store＋台账落盘——**从 11 家账号池语义取并集**（状态机：正常/冷却/耗尽/禁用；分态计数） |
| T-A2 | scaffold main.go.tmpl 增**能力端点层** `/panel/api/*`：tempmail（生成/收件/取码/源管理）、schedule（任务列表/RunNow/档位）、routing（策略/账本）、egress（节点/绑定）、quota（余额/同步）、eventlog（事件）、pool（账号 CRUD/批量）——按 provider.json 段自动挂载（`--without` 不挂载） |
| T-A3 | 面板视图接真数据：临时邮箱视图**全功能化**（免费源预配：temp.tf/g22do/guerrilla/freecustom 出厂即用）＋签到任务/负载/链路/积分视图接端点 |
| T-A4 | 设置视图接配置端点（读/写 provider.json 私有段，原子写无 BOM）＋设计系统保持 |

## 5. 风险与降级

| 风险 | 降级 |
|------|------|
| 通用账号池模型与 11 家存量语义冲突 | pool 包定位为「参考实现内置池」，存量插件可继续用自有池＋routing.Store 镜像（PLT-4 已验证形态） |
| 受控浏览器 CDP 跨 Chrome 版本兼容 | 降级为「v1 手工 F12 导 cookie＋面板粘贴」先跑通全功能 |
| 面板 JS 体量膨胀 | 视图按需懒加载；单文件超 200KB 拆 assets |
| 批次体量超预算 | 批 C 的 geetest_v4 打码通道可独立延后（浏览器人工通道已覆盖） |
