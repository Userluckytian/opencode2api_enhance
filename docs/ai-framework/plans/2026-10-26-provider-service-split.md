# 阶段计划：供应商服务独立端口（自定义源 + 插件供应商）

- 日期：2026-10-26
- 目标：把「自定义模型源」与「插件式供应商」从 OpenCode 免费池链路中剥离，独立到 `127.0.0.1:50080`。
- 决策依据：用户明确要求 50080；Magpie 方案弃用（文件保留，不删）。

## 一、边界

| 端口 | 角色 | 厂商 |
|------|------|------|
| 40000 | 管理面板（UI/API） | 仅管理，不作为对外模型入口 |
| 40080 | OpenCode 统一网关 | 只装 opencode（+ 非 custom 内建） |
| 40100+ | 实例 | 只装 opencode（+ 非 custom 内建） |
| **50080** | **供应商服务** | **只装 custom + 插件（remote）** |

硬约束：

1. 50080 不启动 sidecar、不读实例池、不启 sing-box、不参与节点路由。
2. 40080/实例不再注入 custom 配置；不再启动插件子进程。
3. 插件子进程全局只由 50080 托管一份（避免账号状态/签到/面板端口互相打架）。
4. 管理面板继续管理两类供应商；插件管理 API 由管理进程反代到 50080。

## 二、实现步骤

| # | 任务 | 验收 |
|---|------|------|
| 1 | 新增 `-provider-service` / `-no-plugins` 标志、`provider_port` 配置（env > config > 50080） | `opencode2api -provider-service -port 50080` 可独立启动 |
| 2 | 厂商过滤：provider-service 只注册 `type=custom`；实例/网关剔除 `type=custom`；provider-service 不自动注册内建厂商 | 50080 `/v1/models` 无 opencode 模型；40080 无 custom 模型 |
| 3 | 插件宿主收敛：管理/实例/网关不启插件管理器；provider-service 启；管理面板插件 API 反代到 50080 | 插件进程只有一份；面板「插件式供应商」页仍可用 |
| 4 | 管理器生命周期：启动时拉起 50080、看护重启、退出回收 | 杀 50080 后 10s 内自动恢复 |
| 5 | 前端「供应商服务」卡片：地址/密钥/运行状态/启停 | 卡片显示 `http://127.0.0.1:50080/v1` |
| 6 | 回归：`go build ./...`、`go test ./...`、真实对话 | 40080 免费模型 200；50080 custom/插件 200；停实例后 50080 仍 200 |
